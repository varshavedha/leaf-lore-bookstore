# Leaf & Lore Bookstore

Create a modern, elegant, fully responsive frontend-only e-commerce website named “Leaf & Lore Bookstore.” Implement the requested pages, book browsing/search/filtering, at least 20 sample books, book detail views, localStorage cart with quantity and totals, checkout validation and confirmation, and contact/newsletter interactions. Use a warm cream, green, and brown bookstore aesthetic with professional typography, hover motion, responsive navigation, polished imagery, and accessible UI. No backend or database is needed.
